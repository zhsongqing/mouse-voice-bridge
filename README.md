# Mouse Voice Bridge · 鼠标语音桥

在 Mac 上，用鼠标侧键控制微信输入法语音：**点一下开始说话，再点一下结束并输入文字。**

这是一个用 Swift 编写的小型 macOS 工具。它把 Logi Options+ 发出的 F6 转换成微信输入法能够识别的 Fn 按下／释放事件，让你握着鼠标就能开始语音输入。

> 已在作者的 MacBook Air 13 英寸（Apple Silicon、macOS 15.6.1）＋ Logitech MX Anywhere 3S（蓝牙）＋微信输入法上完成手动验证：侧键点击启动、再次点击停止、识别文字进入输入框。其他设备、系统版本和输入法尚未验证。

## 为什么做这个工具

日常使用 Codex、Claude 等 AI 工具办公时，经常需要输入较长的需求、解释上下文、修改方案。语音输入很方便，但微信输入法常用的「按住 Fn 说话」要求手移回键盘，并持续按住 Fn。

当右手正在用鼠标浏览资料、选中文字或切换窗口时，如果能够直接按鼠标侧键说话，操作会更顺手。这个工具就是为这一步做的：**减少为了开始语音输入而来回移动手的动作。** 它处理的是本机输入事件；即使工作任务在云端运行，语音输入仍发生在 Mac 当前的文本框中，不需要集成任何 Codex 或 Claude API。

## 使用什么鼠标，遇到了什么问题

实际使用的鼠标是 **Logitech MX Anywhere 3S**，选用靠近鼠标前端的侧键作为语音键。后侧键可以继续保留自己的映射，例如回车。

它支持通过 Logi Options+ 自定义按键，但「能自定义」并不等于「每种映射都能直接触发微信语音」。本次尝试的结果是：

| 方案 | 本机观察 |
| --- | --- |
| 实体键盘的微信语音快捷键 | 可以启动语音 |
| Options+ 将侧键设为 Ctrl＋Z 等语音快捷键或宏 | 没有成功启动微信语音 |
| 侧键恢复「前进」，小工具读取原始侧键 | 没有识别到原始侧键 |
| Options+ 将侧键设为 F6，小工具接收 F6 | 可以收到触发 |
| 小工具独立发送 Fn 按下／释放 | 可以唤起微信语音 |
| F6 中转＋点按开关模式 | 已验证开始、停止和文字输入 |

这不代表 Options+ 的所有事件都与微信不兼容，也没有证明底层失败原因。**直接把微信语音快捷键设为 F6，与 Options+ 的 F6 对应，尚未测试。** 这个工具提供的是本机已经跑通的一条路径。

## 它怎么工作

```text
MX Anywhere 3S 前侧键
         ↓ Logi Options+：Keyboard shortcut = F6
鼠标语音桥接收 F6
         ↓ 第一次点击：发送 Fn 按下
         ↓ 第二次点击：发送 Fn 释放
微信输入法「按住 Fn 说话」
         ↓
识别的文字进入当前文本框
```

当前默认是**点按开关模式**：

- 点击一次侧键：工具保持 Fn 按下，微信开始语音输入。
- 再点击一次：工具释放 Fn，微信结束语音输入。
- 最长保持 60 秒，到时自动释放 Fn。

这一模式不要求 Options+ 完整保留鼠标长按的持续时间。实现会在收到中转键释放后等待约 80 毫秒，再切换 Fn 状态，以避免直接在输入回调里立即发送替代事件。

程序同时保留了实验性的「按住说话」、原始侧键识别和 Session 输出选项，但这些不属于当前已经验证的推荐配置。

## 下载或本机编译

### 使用已打包的应用

到本仓库的 **Releases** 下载 Apple Silicon 版本，解压后打开 `MouseVoiceBridge.app`。应用仅做了本地临时签名，没有 Apple Developer ID 签名或公证；系统是否允许直接运行取决于本机安全设置。如无法运行，可以使用下方源码在本机编译。

### 从源码编译

需要 Apple Silicon Mac 和 Xcode Command Line Tools；本机编译验证使用 Swift 5.8，不依赖第三方 Swift 包。

```bash
# 尚未安装开发工具时执行
xcode-select --install

# 在仓库目录执行
bash build.sh
open dist/MouseVoiceBridge.app
```

构建产物在 `dist/`。`build.sh` 会编译 Swift、生成 app bundle 并执行临时签名及签名检查。当前发布包仅验证 Apple Silicon，未测试 Intel Mac。

## 配置：只需三处

### 1. Logi Options+

1. 选择 MX Anywhere 3S，进入按键配置。
2. 在全局配置中选择**前侧键**。
3. 动作设为 **Keyboard shortcut**，快捷键录入 **F6**。
4. 确认侧键标签显示 `F6`。

本机通过实体键盘 **Fn＋F6** 录入成功。工具提供的模拟录入按钮没有成功被 Options+ 识别，因此建议直接用实体键盘录入。Mac 顶部功能键的录入方式可能因系统设置不同而变化，以 Options+ 最终显示的 `F6` 为准。

如果某个应用有单独的 Options+ 配置，它可能覆盖全局映射；在那个应用中也需要确认前侧键对应 F6。

### 可选：后侧键设为回车，说完直接发送

为了让整段操作都能用鼠标完成，可以在 Options+ 中选择**靠近手腕的后侧键**，将动作设为 **Keyboard shortcut**，按一次实体键盘的回车键，确认显示 **Return（回车）**。

这样两个侧键各司其职：

| 鼠标按键 | 配置 | 用途 |
| --- | --- | --- |
| 前侧键 | F6 → 语音桥 → Fn | 点一下开始语音，再点一下结束 |
| 后侧键 | Return（回车） | 识别文字输入完成后，发送消息 |

日常操作就是：**点前侧键开始说话 → 再点前侧键结束 → 等待文字出现并确认内容 → 点后侧键发送。** 不用再把手移回键盘按回车。

发送效果取决于当前应用：只有输入框设置为「回车发送」时，后侧键才会发送；如果回车用于换行，它就会换行。这个映射直接由 Options+ 完成，不需要语音桥处理，也不会在语音结束后自动发送。若有应用专属配置，也要在该配置里设置后侧键。

### 2. 微信输入法

进入微信输入法设置 → 语音输入：

- 开启 **按住说话**。
- 将该快捷键设置为 **Fn**。
- 确认微信输入法可以使用麦克风。

语音桥不负责声音采集或识别，仍使用微信输入法和电脑已有的麦克风。

### 3. 鼠标语音桥

1. 打开 `MouseVoiceBridge.app`，会显示普通窗口和菜单栏入口「语音键」。
2. 点击「启动」。首次使用，在 macOS 系统设置 → 隐私与安全性 → 辅助功能中，允许此应用。
3. 回到工具再次点击「启动」，确认状态为「已启动，等待侧键或 F6」。
4. 保持 **模式：点按开关** 和 **输出：HID**。
5. 在一个空白文本框中点击前侧键，说一句话，再点击前侧键结束。

**F6 中转方案不需要点击「识别侧键」。** 该按钮仅供实验性的原始鼠标事件模式使用。

## 日常使用

- Options+ 的设置窗口可以关闭，但当前方案依赖它的后台服务发出 F6。
- 语音桥也需要保持运行；可以关闭其窗口，之后通过 Dock 重新打开。点击「退出」会停止桥接。
- 应用不会自动设置开机启动。重新启动应用后，需要点击「启动」。
- **实体键盘 F6 也会触发语音桥**，运行期间不再保持它原有的用途。
- 当前实现没有按鼠标设备隔离原始侧键映射；其他鼠标的同编号侧键也可能触发工具。
- 暂停、正常退出、睡眠或用户会话停用时会释放 Fn；恢复使用前需重新启动监听。
- 如需立即结束工具保持的 Fn 状态，点击「立即释放 Fn」。

## 排错

| 现象 | 检查方法 |
| --- | --- |
| 点击侧键，触发计数不增加 | 检查工具是否已启动、辅助功能权限、Options+ 是否运行、当前应用是否覆盖了 F6 映射 |
| 计数增加，但语音不出现 | 确认微信「按住说话」为 Fn，工具为点按开关＋HID，并在普通文本框中测试 |
| 需要区分鼠标接收与 Fn 输出问题 | 点击「独立测试 Fn」，在 5 秒内把光标放到文本框；工具保持 Fn 3 秒后释放 |
| 按住模式失败 | 回到已经验证的点按开关模式；窗口会显示中转事件的按住时长，便于诊断 |
| 重新编译后权限异常 | 系统可能要求重新授权更新后的应用 |
| 应用被强制结束后修饰键状态异常 | 手动按下并松开实体 Fn；强制结束无法执行正常的退出清理 |

「已发送 Fn」仅表示工具发出了事件，不代表微信已经开始录音。应以微信语音面板和最终输入的文字为准。

## 隐私与权限

代码不访问网络、不采集声音、不保存输入文本，也没有账号、遥测或语音识别服务。辅助功能权限用于监听并转换输入事件；它是较广泛的系统权限，可以随时在系统设置中撤销。

事件监听器会接收键盘按下／释放和其他鼠标按钮事件，只处理配置的侧键与 F6，其余事件放行，不存储键盘文本。持久化内容只有原始侧键模式所选的按钮编号。微信输入法自身如何处理语音和文字，由微信输入法的设置与隐私政策决定。
